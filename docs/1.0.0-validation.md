# Bootdisk Web 1.0.0 – produksjonsgodkjenning

Den 17. september 2026 ble `1.0.0-rc1` lastet opp til `bootdisk.no` og godkjent som grunnlag for Bootdisk Web 1.0.0.

## Beståtte porter

- Produksjonen rapporterte riktig kandidatversjon.
- Alle 39 kildeposter og 136 publiserte filer bestod HTTP- og SHA-256-verifikasjon.
- Sitemap inneholdt arkivoversikten og nøyaktig 39 detaljlenker.
- Arkivoversikten viste 39 av 39 poster uten nettleserfeil fra nettstedet.
- Søk etter Winamp ga riktig K37-post og åpnet Winamp 2.76.
- Forrige/neste viste menneskelige programnavn; høyre piltast åpnet WinZip 8.0.
- Canonical-URL for K37 ble satt til den stabile K-ID-baserte detaljlenken.
- Desktopvisningen ble kontrollert i produksjon.
- Mobilvisningen ble kontrollert og godkjent av produkteier i produksjon.

## Promotering

1.0.0 inneholder ingen funksjonelle endringer fra den godkjente kandidaten. Kun versjonsmarkøren og releasedokumentasjonen endres ved promotering.
