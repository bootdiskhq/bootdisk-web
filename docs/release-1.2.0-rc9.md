# 1.2.0-rc9 — arkivkort uten kildekoder

K38, I12 og andre kildekoder er fjernet fra arkivkortene. Kortene gir mer plass til programnavn, CD og status. Kildekoder beholdes i detaljvisningen, søk, lenker og datagrunnlag. Alle 369 postfiler og mediefiler er uendret fra rc8.

Rc9 erstatter rc8 som opplastingspakke. Eksisterende testpakke og direkte nettleserkontroll brukes til verifikasjon.
