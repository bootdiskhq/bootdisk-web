rc22 published seven 2008–2009 CDs without screenshots and omitted 20 PNG
screenshots from 16/2002. Ingest recognized JPG/BMP but not PNG or Norwegian
ShotNo variants. HTTP verification proved package integrity, not image discovery
completeness. Ingest PR 26 fixes discovery with Norwegian/neutral same-folder
selection and rejection of case ambiguity; its CI passed before merge.

batch now have screenshots. The collection remains 1551 posts on 26 CDs, with
3130 image objects/derivatives and 1838 public update events. The 1529 prior
events remain intact; 309 image updates are added with the actual release date.

with earlier observations. Only assets and associated Catalog file occurrences
change in 309 entry documents. Other entry fields and human decisions are
unchanged. Image-only preservation extraction verifies original bytes; Publish
verifies them again. Screenshot minimums now match independently checked source
coverage. Removing one screenshot from the 43-post 10/2008 CD fails the release
gate (42 < 43).

Validation: Ingest 218 tests, 158 passed and 60 optional tests skipped. Full local
HTTP package verification passed for 1551 entries, 3130 images and 1838 events.

entry documents/index/history, and compares every changed/new file via HTTPS.
