# Bootdisk Web 1.0.0-rc1 – validering

Kandidaten ble bygget 17. september 2026 fra de autoritative resultatene for K-CD 15/2001.

## Bestått før produksjon

- Frontend-datakontrakten validerte alle 39 kildeposter.
- Releasebygget pakket 39 detaljdokumenter og 136 unike publiserte filer.
- Sitemap inneholder arkivoversikten og 39 stabile detaljlenker.
- Release-rapporten identifiserer frontend-projeksjonen og Publish-manifestet med SHA-256.
- Alle pakkede ressurser bestod innholdsadressert SHA-256-kontroll over lokal HTTP.
- Arkiv, K37, 404, `robots.txt` og sitemap bestod deploy-verifikatoren.
- Testpakken bestod 21 av 21 tester med Python 3.12.
- GitHub Actions var grønn for begge forberedende RC-PR-er.

## Gjenstår på målserver

- Last opp kandidaten til `bootdisk.no` etter sikkerhetskopi av gjeldende `/www`.
- Kjør komplett produksjonsverifikasjon av 39 poster og 136 filer.
- Kontroller arkiv og detaljside visuelt på mobil- og desktopbredde.
- Bekreft at ingen blokkerende tilgjengelighets-, integritets- eller deployfeil finnes.

Når alle punktene er bestått kan samme kandidat promoteres til `1.0.0`. Nye funksjoner hører til etter 1.0.
