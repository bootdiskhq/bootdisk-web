# 1.2.0-rc8 — lesbar merking av verktøyposter

Rc7 viste de interne `Tool`-nøklene fra Director-importen i kort, kildepostfelt og navigasjonsmerking. Disse er kodede koblingsnøkler, ikke navn trykt på CD-en. Visningen bruker nå «Verktøymenyen». Programnavn, URL-er, kildebelegg, kuratering og alle 369 postfiler er uendret. Andre opprinnelige kildenøkler som K1 og I12 vises som før.

Rc8 erstatter rc7 som opplastingspakke. Samme 162 nye verktøyposter og dokumenterte kildeavvik følger med. En regresjonskontroll dekker lesbar merking og uendrede nøkler. Nettleserkontroll dekker både arkivkort og detaljside.
