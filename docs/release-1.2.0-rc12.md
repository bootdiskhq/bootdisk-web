# Bootdisk 1.2.0-rc12

Publiserer 88 identifiseringsforslag godkjent av Stian 15. oktober 2026, fordelt på sju CD-er. 74 har kjent versjon, 14 beholder ukjent versjon. Katalogens kildegrunnlag merker ni slutninger fra samsvarende referansefiler som tolkninger; installasjonsinnholdet er ikke dekodet for disse. 23 teknisk uavklarte poster forblir uavklart.

Katalogpakke: `data/curation/approved-2026-10-15.json`, med separat revisjonsrapport. Frontendens navn, versjon og status kommer fra de validerte kataloggrafene. Originalomtaler, bilder, RTF-er, URL-er og kildekontekst er bevart. 281 av 369 postfiler er byte-identiske med rc11. De 816 mediefilene er uendret. Rc11s cachekontroll beholdes. Ingen kurateringsverktøy eller private arbeidsfiler publiseres.
