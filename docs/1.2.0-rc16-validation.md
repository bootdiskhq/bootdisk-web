# 1.2.0-rc16: dokumenterte CD-kilder

426 poster fra sju CD-er, 832 bilder. 194 tidligere pending-poster vises som «Oppgitt på CD-en». Dette bekrefter navnet i kilden, ikke innholdet i programfilen. Ti filkoblinger er fortsatt maskinoppgaver, og alle kildeavvik beholdes. Eksisterende identifikasjoner, versjoner, omtaler og kladder er uendret.

Catalog PR 50 og Web PR 62 er merget etter grønn CI. Lokal testpakke: Catalog 156 kjørt, 155 bestått, 1 hoppet over. Web 322 kjørt, 214 bestått, 108 hoppet over. Nettleserkontroll i appen bekreftet samsvar mellom detaljside og arkivfilter.

Historikk v3 er rekonstruert fra rc11–rc15 med opprinnelige publiseringstidspunkter; samtlige 200 historiske hendelser er uendret. Rc16 legger til 194 statusoppdateringer, ingen nye poster. Registeret inneholder dermed 394 hendelser. Endrede JavaScript-filer har nye cache-nøkler.

Publiseringsløpet tar bytekontrollert sikkerhetskopi av alle filer som erstattes, laster opp data før HTML-inngangene og kontrollerer alle opplastede filer over HTTPS. Kvittering og sikkerhetskopi lagres lokalt i rc16-release-2026-10-15. Denne filen er ikke en kvittering for fullført opplasting.
