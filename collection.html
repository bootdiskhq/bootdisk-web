Om kildepostene

Hver CD vises som en liste med kildeposter, én for hvert valg i CD-menyen. Omtalene er gjengitt fra CD-en uten omskriving. Samme program kan finnes på flere CD-er, og for mange poster er det ennå ikke avklart nøyaktig hvilket program eller hvilken utgave det gjelder.
